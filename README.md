# WorkDesk

![Build](https://github.com/modeAlohadance/workdesk/actions/workflows/ci.yml/badge.svg)

Нативное приложение для Windows на **C++17 и Win32 API**. Без аккаунта, сети и установки дополнительных пакетов.

## Возможности

- Задачи с тремя приоритетами, отметкой выполнения и фильтрами.
- Заметки с ручным сохранением и сохранением при закрытии приложения.
- Таймер фокусировки: 25 минут, пауза, сброс, звуковой сигнал.
- Экспорт всех задач в CSV с UTF-8 BOM для Excel.
- Локальное хранение: `%LOCALAPPDATA%\WorkDesk`, замена файлов через временный файл.

Задачи сохраняются при добавлении, удалении и смене статуса. Заметки — кнопкой «Сохранить всё» или при закрытии. Таймер работает, пока открыто приложение; после перезапуска начинает новую сессию. Удаление задачи требует подтверждения.

## Скачать

[Windows x64 — EXE и контрольная сумма](https://github.com/modeAlohadance/workdesk/releases/latest).
Скачайте `WorkDesk.exe` и запустите. Сборка не подписана цифровым сертификатом.

## Сборка из исходников

Windows 10/11, Visual Studio 2022 с компонентом Desktop development with C++, CMake 3.20+.

```powershell
cmake -S . -B build -A x64
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
.\build\Release\WorkDesk.exe
```

Тесты ядра также собираются на Linux/macOS через CMake; графический интерфейс предназначен для Windows. Статическая C++ runtime включена в EXE.

## Архитектура и проверки

`src/main.cpp` — интерфейс и события; `src/tasks.hpp` — проверяемое ядро; `src/ui.hpp` — Unicode, CSV, диалоги и запись файлов.

GitHub Actions компилирует исходники, запускает CTest и `WorkDesk.exe --smoke` с ограничением времени. Проверка запуска автоматически закрывает окно; использует отдельную временную папку и проверяет сохранение задач. Публичные релизы создаются из прошедшего проверки коммита и содержат SHA256SUMS.txt.

## Ограничения и развитие

Интерфейс имеет фиксированный размер. Нет синхронизации, напоминаний и поддержки нескольких одновременно открытых экземпляров. Файлы задач и заметок сохраняются по отдельности; резервную копию можно сделать копированием папки данных.

Предложения и сообщения об ошибках приветствуются в Issues. Лицензия MIT.
